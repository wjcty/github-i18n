# GitHub-i18n 人工配置文档（MVP）

按顺序完成以下配置后，再配合《快速启动说明.md》启动服务。

---

## 1. GitHub App 注册

1. 打开 GitHub → **Settings** → **Developer settings** → **GitHub Apps** → **New GitHub App**。
2. 建议填写：
   - **GitHub App name**：全局唯一（记下 slug，对应 `GITHUB_APP_SLUG`）。
   - **Homepage URL**：浏览器访问的前端地址（本地联调一般为 `http://localhost:3001`）。
   - **Callback URL**：`http://localhost:3001/api/auth/callback/github`（经前端反代到后端，**不要**填 3123）
   - **Setup URL（可选）**：`{APP_URL}/dashboard?installed=1`（前端路由尚未实现时可先填首页）。
   - **Webhook URL**：`{APP_URL}/api/webhooks/github`
   - **Webhook secret**：随机字符串 → 写入 `GITHUB_APP_WEBHOOK_SECRET`
3. 勾选 **Request user authorization (OAuth) during installation**（或安装后引导用户授权）。
4. 建议启用 **Expire user authorization tokens**（后续可接 refresh；MVP 依赖重新登录刷新 token）。

### Repository permissions

| 权限 | 级别 |
|------|------|
| Metadata | Read |
| Contents | Read and write |
| Pull requests | Read and write |

### Account permissions

| 权限 | 级别 |
|------|------|
| Email addresses | Read |

### Subscribe to events

- `push`
- `installation`
- `installation_repositories`

### 安装与凭据

1. 创建 App 后记录 **App ID** → `GITHUB_APP_ID`
2. 生成 **Private key**（PEM）→ `GITHUB_APP_PRIVATE_KEY`（单行环境变量时用 `\n` 表示换行）
3. **Client ID / Client secret** → `GITHUB_APP_CLIENT_ID` / `GITHUB_APP_CLIENT_SECRET`（同时填入 `AUTH_GITHUB_ID` / `AUTH_GITHUB_SECRET`）
4. 在目标账号/组织下 **Install App**，并授权访问需要翻译的仓库。

---

## 2. OpenRouter

1. 注册 [OpenRouter](https://openrouter.ai/) 并创建 API Key。
2. **BYOK 模式**：用户在平台 Settings 页面填写 Key（后端加密存储）。
3. **PLATFORM 模式（可选）**：在 `.env` 配置 `OPENROUTER_PLATFORM_KEY`，并设置 `PLATFORM_MONTHLY_CHAR_LIMIT`。
4. 调用会使用请求头 `HTTP-Referer: APP_URL`、`X-OpenRouter-Title: GitHub-i18n`（与 OpenRouter 文档一致）。

---

## 3. 环境变量

复制 `.env.example` 为 `.env` 并填写：

| 变量 | 说明 |
|------|------|
| `DATABASE_URL` | MySQL 连接串 |
| `AUTH_SECRET` | `openssl rand -base64 32` 或 Node 生成随机串 |
| `AUTH_GITHUB_ID` / `AUTH_GITHUB_SECRET` | 与 GitHub App Client 相同 |
| `GITHUB_APP_*` | 见上文 |
| `ENCRYPTION_MASTER_KEY` | 32 字节 Base64：`node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"` |
| `APP_URL` | 对外访问地址（OAuth、Webhook、OpenRouter Referer） |

**注意**：`ENCRYPTION_MASTER_KEY` 丢失后无法解密已存的用户 Key 与 GitHub Token，请务必安全备份。

---

## 4. 本地 MySQL

使用项目 `docker-compose.yml` 中的 `mysql` 服务，或自建 MySQL 8.x，并创建库 `github_i18n`。
