# GitHub-i18n 前端 · 快速启动说明

本文档说明如何在 **Windows** 上运行 `web/` 目录下的 Next.js 15 前端，并与后端 API 联调。

## 前置条件

| 依赖 | 说明 |
|------|------|
| Node.js | 建议 20+（与 create-next-app 一致） |
| Git Bash | 推荐用 Git Bash 执行下列命令 |
| 后端服务 | 已按《后端 API 接口文档》启动，默认 `http://localhost:3000` |
| Python 3 | 可选；仅用于 ui-ux-pro-max 设计脚本，运行前端不强制 |

## 1. 安装依赖

在 **Git Bash** 中：

```bash
cd /e/project-ai/github-i18n/web
npm install
```

## 2. 环境变量

复制示例并按需修改：

```bash
cp .env.example .env.local
```

| 变量 | 含义 |
|------|------|
| `API_URL` | 后端根地址，开发默认 `http://localhost:3000` |
| `NEXT_PUBLIC_APP_URL` | 浏览器访问的前端地址，开发默认 `http://localhost:3001` |

前端通过 [next.config.ts](./web/next.config.ts) 将 `/api/*` **反向代理**到 `API_URL`，会话 Cookie 仍由浏览器对前端源站发起请求，便于本地联调。

**OAuth 提示**：后端 `APP_URL` 需与你在浏览器中打开的前端地址一致（开发环境一般为 `http://localhost:3001`），否则 GitHub 回调或 Cookie 可能异常。

## 3. 启动开发服务器

```bash
npm run dev
```

浏览器访问：**http://localhost:3001**

## 4. 推荐联调流程

1. 首页 **GitHub 登录** → `/api/auth/signin/github`（代理至后端）
2. 安装 GitHub App（首页或导入对话框中的链接）
3. **仪表盘** → 导入仓库 → **翻译配置**（语言、文件树、ignore、自动同步）
4. **设置** → 配置 OpenRouter Key（BYOK）或平台配额模式
5. 仓库详情 → **全量/增量翻译** → **任务详情**（SSE/轮询进度、预览、打开 PR）

## 5. 生产构建

```bash
npm run build
npm run start
```

生产环境通常与后端同域部署，可省略代理，直接由同一 Next 实例提供 `/api`；若前后端分离部署，请保持 `API_URL` 与 CORS/Cookie 策略与后端一致。

## 6. 页面路由（MVP）

| 路径 | 功能 |
|------|------|
| `/` | 产品介绍、登录 |
| `/dashboard` | 仓库列表、导入 |
| `/repo/[id]` | 仓库详情、发起翻译、任务历史 |
| `/repo/[id]/config` | 语言、范围、ignore、Webhook 开关 |
| `/task/[id]` | 进度、预览、PR、失败重试 |
| `/settings` | OpenRouter、模型、删除账户 |

## 7. 常见问题

**接口 401 / 无法登录**  
确认后端已启动，且 `API_URL` 正确；检查后端 Auth 与 GitHub App 配置。

**创建翻译任务 403**  
常见原因：GitHub 主邮箱未验证、BYOK 未配置 Key、平台配额用尽（见 API 文档）。

**EventSource 断开**  
任务页会自动 2s 轮询 `GET /api/tasks/{id}` 作为 SSE 兜底。

**Git Bash 路径**  
Windows 盘符在 Git Bash 中为 `/e/project-ai/...`。
